# Glossario della localizzazione italiana

Scelte terminologiche per l’interfaccia di Tine. I nomi di prodotto e la sintassi dei file delle note restano invariati.

- `page` → pagina
- `block` → blocco
- `journal` → diario
- `graph` → grafo
- `task` → attività
- `query` → interrogazione (nelle etichette brevi può restare “query” quando indica la funzione di Tine)
- `outliner` → editor a struttura
- `backlink` → riferimento in entrata
- `settings` → impostazioni
- `shortcut` → scorciatoia
- Tine, Logseq, Markdown, PDF, CSV, Org e nomi di comandi/proprietà restano invariati quando fanno parte di sintassi o identificatori.

Usare il tono informale e frasi brevi, coerenti con l’interfaccia originale.
